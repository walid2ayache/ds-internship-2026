What is a feature vector?

It is the same 188-feature representation used in the Explorer: 93 local transaction features, two log-degree values, and 93 neighbour-contrast values. A raw transaction cannot be scored without its graph context — if you paste arbitrary zeros or unrelated numbers, the score is not meaningful. Paste full-precision values: rounding a feature can move the score.

What the numbers do not say

Validation is saturated and anti-correlated with test. The final fit uses validation labels, so 0.803 is a deployment-style number, not a held-out model-selection result. The comparable train-only result is 0.796 PR-AUC / 0.754 F1.

ABOUT THE BUILD

From graph features
to a live score.

A portfolio project on the Elliptic Bitcoin dataset. The honest finding: graph message passing did not beat a strong tabular model — graph-derived features did.

How a score is made

  1. 01
    Graph-aware features. 93 local transaction features, log in/out degree, and 93 neighbour-contrast features (x_local − mean(neighbour x_local)).
  2. 02
    XGBoost ensemble. Five seeded models, 332 trees each, trained on steps 1–34. Probabilities are averaged.
  3. 03
    Explain. XGBoost contributions show which features pushed the score toward illicit or licit, in log-odds.

Limitations

  • Validation is saturated. ~0.95 PR-AUC on val does not rank configs; test is the only honest check.
  • Prior shift. Thresholds tuned at 16.8% prevalence are applied at 6.5%; steps 43–49 have only 2–56 positives each.
  • Final fit uses val labels. 0.803 is deployment-style; 0.796 is the train-only comparison.
  • Graph context is required. Degree and contrast features need the transaction graph; this is not a plug-in scorer for arbitrary raw rows.
  • Demo only. Historical labelled nodes, not a production fraud system.

API

The demo is a live model, not a static mock. Score a 188-feature vector with:

curl -X POST http://127.0.0.1:8000/api/predict \
  -H "Content-Type: application/json" \
  -d '{"features": [ ...188 floats... ]}'

Endpoints: /api/meta, /api/transactions, /api/transaction/<id>, /api/predict.

Stack

Python stdlib HTTP server · XGBoost 3.4 · NumPy · vanilla HTML/CSS/JS · no frontend framework, no external CDN. The same code runs locally and behind a Procfile.
